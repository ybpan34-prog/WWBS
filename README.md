# wwbs

wwbs 是一个面向《鸣潮》Windows PC 客户端的图像识别自动点击工具。它会识别游戏窗口中的模板图片，并按照任务配置自动点击目标位置。

当前版本：`1.4.7`

程序顶部的“关于”按钮可查看当前版本，并跳转至作者的 [B 站视频](https://www.bilibili.com/video/BV1aPuo6uE9r/) 和 [GitHub 仓库](https://github.com/ybpan34-prog/WWBS)。

项目地址：<https://github.com/ybpan34-prog/WWBS>

## 当前功能

- 自动检测简体 `鸣潮`、繁体 `鳴潮` 和国际服 Steam 版 `Wuthering Waves` 窗口。
- PC 客户端优先离屏捕获游戏客户区，不受 wwbs 或其他窗口遮挡；不支持时自动置前游戏兜底。
- 按 `1920x1080` 模板基准进行识别，并实际支持 `1600x900`、`1536x864`、`1280x720` 等 16:9 等比例窗口。
- 显示游戏窗口预览、运行日志和识别结果。
- 支持制作、刷新、删除模板图片。
- 支持模板组：一组 `menu1.png` 到 `menu99.png` 图片属于一个完整任务模板组。
- 默认模板组名称为“幻梦游园”。
- 任务可以绑定不同模板组，切换任务时自动切换对应图片组。
- 第一阶段识别并点击 `menu1.png`，之后按顺序识别 `menu2.png` 到 `menu99.png`。
- 每次图像识别点击都会在模板方框内部随机选择安全位置，并保留原有点击偏移。
- 每次点击后的间隔会在任务固定值的 `±0.2 秒` 范围内随机。
- 支持“周常拿满奖励”和“周常拿满星声”两种自动停止模式。
- 下一张模板累计识别失败 2 次和 4 次时，会回退确认并补点仍停留在画面的上一张模板。
- 最后一轮会确认末模板已响应点击；仍停留时最多补点 2 次。
- 支持手动停止任务，并在累计 5 次找不到目标模板时自动停止。
- 概率计算支持星声、抽数、角色水位、武器水位、角色大保底和目标数量。
- 支持查看历史更新公告。
- 支持从 GitHub Releases 检查、下载和安装远程更新。
- 加入 Q 版桌宠“达妮娅”“爱弥斯”和“景燃”，程序状态会触发待机、检查、等待、运行、完成和失败动画及气泡提示；空闲时按随机间隔触发互动动作，景燃还会以 16 个方向跟随鼠标观察。
- 右键桌宠可诊断管理员权限、游戏窗口、分辨率、模板，以及是否位于无存档的小漂泊者初始界面。
- 右键桌宠可直接执行拿满奖励、拿满星声和停止任务；由桌宠触发时不再重复弹出开始确认。
- 自动任务无法启动或运行失败时会快速诊断并即时反馈，不再把运行条件问题描述为截图模糊。
- 图像匹配使用 NumPy 内置实现，不再依赖 SciPy。
- 支持全局快捷键 `Ctrl + Alt + S` 紧急停止当前任务，即使焦点位于游戏窗口也可使用。
- 加入可选“达妮娅主题”“爱弥斯主题”和深色青金“景燃主题”；原版简约主题保持默认。选择角色主题时会绑定对应桌宠，但单独选择桌宠不会再改变程序主题。
- 新增“群声共振模拟域”任务：用户选择关卡后，程序会点击开始模拟、在固定镜头下靠近蓝色守岸人并按 F 交互。
- 新增独立“4C刷取”10次与30次循环，支持持续普攻、定时技能、每5秒大招就绪检测、三号位回血连段、每0.5秒首领状态检查、声骸搜索吸收与重新挑战。
- 大招仅在右下角出现彩色完整亮环时触发，适配绿色、蓝色、黄色等角色配色；灰蓝完整圈、暗圈、残缺圈和倒计时状态均视为未充能。检测使用战斗截图，不暂停持续普攻，也不会插入三号位回血连段。
- 4C刷取按钮会直接使用内置4C模板，不需要先在模板管理中切换模板组；吸收阶段会核验“吸收”文字，不会把相同外框的“领取奖励”误判为吸收。
- 新增正式版“一键日常”：滑动选择指定无音区后自动完成两轮挑战、双倍领取、活跃度100宝箱与先约电台免费奖励；体力不足时只使用结晶单质或结晶溶剂，绝不会消耗星声。日常收尾会再次检查周度游历，未完成时自动进入幻梦游园、补选第一个祝福技能并接续15轮“周常拿满奖励”，已有完成勾则跳过。
- 一键日常进入索拉指南后会先检查活跃度页面；若活跃度已满并被游戏自动切页，会提示今日日常已完成并跳过无音区，但仍继续检查周度游历：停在周常页则执行幻梦游园，已跳到后续页面则结束。
- 周常启动只通过中央“＋ / 选择祝福”判断空槽；单独周常与日常衔接周常均会在空槽时自动选择第一个祝福，只要不是加号，任意已装备祝福都可直接开始。
- 日常奖励光球采用0.65最低置信度和分层视角扫描：先搜索当前高度，必要时逐级抬高，搜索循环结束会恢复初始高度，避免镜头过低或过高。
- 设置页可选择是否启用日常三号位回血；默认关闭，开启后会暂停一号位普攻、执行回血连段并自动切回一号位。
- 日常战斗会同时检查清理目标文字、奖励光球和“领取奖励”提示；即使目标文字残留，也会停止攻击并进入奖励搜索。
- 第二轮完成后会安全识别“确认离开”二次提示并点击右侧确认；未出现弹窗时不会盲点固定坐标。
- 补充体力界面会等待资源数字稳定并多帧判断：结晶单质为0时直接选择结晶溶剂；补充后仍不足也会自动改用溶剂，始终不会选择星声。
- 桌宠支持多档大小调整，程序窗口会根据不同屏幕尺寸等比例适配，日志与设置页面支持滚动。
- 一键日常、一键周常与4C刷取按钮旁提供圆圈问号提示；点击后会显示对应的16:9启动页面示例，并提醒先把游戏调整到正确画面。

## 使用前准备

1. 请以管理员身份运行软件；Steam 国际服同样需要让 wwbs 与游戏保持一致的权限级别。
   点击真实运行按钮时，若检测到 wwbs 尚未使用管理员权限，程序会立即请求管理员权限并重启，不再等到任务报错；请在 Windows 提示中选择“是”。预演模式不会触发提权。
2. 将游戏设置为 `1920x1080`，或者使用等比例缩放的窗口分辨率。
3. 请先完成周本的新手教程。
4. 将游戏速度调整至 `MAX`。
5. 让游戏停留在带“开始游戏”按钮的小漂泊者初始界面，并确保没有存档。

## 直接运行

推荐普通用户使用 GitHub Release 中的 `wwbs-exe.zip`：

1. 下载并解压 `wwbs-exe.zip`。
2. 保持 `wwbs.exe` 和 `_internal` 文件夹在同一目录。
3. 右键 `wwbs.exe`，选择“以管理员身份运行”。
4. 窗口标题保持“自动”，在“开始”页面选择任务；启动任务时程序会自动检测游戏窗口。
5. 点击“周常拿满奖励”或“周常拿满星声”。
6. 需要提前结束时，点击“停止当前任务”，或按全局快捷键 `Ctrl + Alt + S`。

“一键日常”需要角色先处于可按 Esc 打开终端的大世界。程序会经终端进入索拉指南；请在开始页滑动选择无音区，再点击“一键日常（2轮双倍）”。完成日常领奖后，程序还会从终端检查周度游历：未完成时进入幻梦游园，技能槽为空才选择第一个祝福，然后自动执行15轮；已有完成勾或已有技能时不会重复操作。
设置页可选择是否在日常战斗中启用三号位回血连段；该选项默认关闭，开启并保存后会定时切换三号位，完成回血后自动切回一号位。

## 桌宠

- 左键拖动可移动达妮娅、爱弥斯或景燃，双击可触发互动动作。
- 右键可运行诊断、检测游戏窗口、执行自动任务、停止任务、开关漫游或隐藏桌宠。
- 桌宠隐藏状态会自动保存并在下次启动时恢复；自动任务和一键操作的状态提示不会把已隐藏的桌宠重新显示。
- 三位桌宠会使用各自的人格台词，并自然地称呼你为“漂泊者”；景燃会使用“行于阴阳未判之处……”等专属台词。自动任务执行期间会暂停漫游，避免遮挡模板位置。
- “帮我诊断”会检查权限、窗口比例、截图、配置、模板和正确起始界面，并把详细结果写入日志。

## 程序主题

- 默认继续使用原版简约主题。
- 可在“设置 → 程序主题”中启用“达妮娅主题”“爱弥斯主题”或“景燃主题”，切换后程序会自动重启。
- 主题与桌宠角色自动绑定；选择原版简约主题时可单独选择桌宠。
- 三款角色主题都使用独立压缩资源，景燃主题采用用户提供的青蓝幽火头图与深色青金配色。

“先预演一次”只识别模板，不会实际点击，适合开始前检查模板是否正确。

## 模板组

模板图片位于 `templates/` 文件夹中。

默认模板组直接使用 `templates/` 根目录中的图片：

```text
templates/menu1.png
templates/menu2.png
templates/menu3.png
...
templates/menu99.png
```

其他任务模板组使用独立文件夹：

```text
templates/
  幻梦游园/
    menu1.png
    menu2.png
    ...
  其他任务/
    menu1.png
    menu2.png
    ...
```

在“模板”页面中可以：

- 新建模板组。
- 选择模板组并制作图片。
- 将当前模板组绑定到“开始”页面选中的任务。
- 删除当前模板组。

模板最好包含按钮文字、图标、边框等稳定特征，不建议只截取纯色背景。

## 概率计算

“概率”页面支持填写：

- 星声数量，或者抽数，二者会自动同步。
- 角色水位。
- 武器水位。
- 是否拥有角色大保底。
- 想要获得的 UP 角色数量。
- 想要获得的 UP 武器数量。

换算规则为 `160 星声 = 1 抽`。抽数最多允许 `1000` 抽。复杂计算会在后台执行，避免界面卡死。

角色池按 50% 和大保底计算；武器池按当前设定默认 5 星即为 UP。角色和武器目标同时填写时，程序默认先计算角色目标，再用剩余抽数计算武器目标。

## 源码运行

环境要求：

- Windows
- Python 3.10 或更高版本

安装依赖：

```powershell
pip install -r requirements.txt
```

启动：

```powershell
python app.py
```

也可以双击：

```text
启动 wwbs.bat
```

## 主要文件

- `app.py`：主界面、任务执行、概率计算和远程更新。
- `windows_client.py`：Windows 游戏窗口检测、截图和鼠标点击。
- `image_matcher.py`：模板图像识别。
- `desktop_pet.py`：桌宠窗口、动画、气泡和右键菜单。
- `daniya_persona.py`：达妮娅的人格台词与事件语言。
- `aemeath_persona.py`：爱弥斯的人格台词、欢迎与事件语言。
- `pet-assets/`：桌宠运行时动画帧。
- `optional-themes/`：可选程序主题包。
- `weekly_tasks.json`：任务和循环配置。
- `templates/`：默认模板组和其他模板组。
- `wwbs.ico`：程序图标。

## GitHub 远程更新

程序会检查以下 GitHub Releases 地址：

<https://github.com/ybpan34-prog/WWBS/releases>

每个正式 Release 必须上传一个名称完全相同的文件：

```text
wwbs-exe.zip
```

用户点击程序顶部的“检查更新”后，程序会：

1. 查询最新 Release。
2. 对比当前版本号。
3. 下载新的 `wwbs-exe.zip`。
4. 关闭当前程序。
5. 替换程序文件并自动重启。

源码模式只能检查版本，自动替换功能需要使用打包后的 `wwbs.exe`。

## 发布新版本

1. 修改 `app.py` 中的 `APP_VERSION`。
2. 重新生成 `wwbs-exe.zip`。
3. 创建新的 Git 标签，例如 `v1.4`。
4. 在 GitHub 创建同名 Release。
5. 将 `wwbs-exe.zip` 上传到该 Release。
6. 在 Release 描述中填写本次更新内容。

不要修改发布文件名，否则客户端无法找到更新包。

## 注意事项

- 本工具只对当前桌面上的游戏窗口执行图像识别和鼠标操作。
- 请先使用“先预演一次”确认模板位置正确。
- 不要在游戏新手教程尚未完成时启动自动任务。
- 识别异常时可以查看“日志”页面，并使用模板组功能重新制作图片。
